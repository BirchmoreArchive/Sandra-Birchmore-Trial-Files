## Reading convention

Each published day should preserve chronological order and source provenance. Where available, entries will link back to the original GSE reporting. Editorial additions or later source material should be clearly distinguished from GSE's reporting rather than silently incorporated into it.

The structure is intentionally basic until the archive has a reason to become more complicated.
